1. **Run Migrations**
   ```bash
   php artisan migrate
   ```
   This will create all 45+ tables with proper relationships.

2. **Seed Initial Data** (Optional)
   ```bash
   php artisan db:seed
   ```
   Populate with sample data for testing.

3. **Start Services**
   ```bash
   php artisan serve
   php artisan queue:work
   ```
